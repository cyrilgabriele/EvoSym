\subsection{Lessons learned on the domain}

Four domain choices would change. Rounding: the sheet is silent on fractional Rappen, and the domain expert's floor rounding and the auditor's half-up oracle disagreed in four cases (Section~\ref{sec:audit-results}); such conventions belong in the spec before code. Relative dates (``last Saturday'') and return tickets were never specified. The ticket price is the only input the knowledge base cannot confirm; answering with the percentage and leaving the amount to SBB would remove it. Real refund journeys, rare that day, were mined slowly after FlightMode and stayed local; committed early, they would have given all roles the same test cases.
